API 访问

关闭时，AI 只要知道地址就能调用（默认关闭）
默认不需要 token：在自家局域网里，让 AI 只记住 http://NAS_IP:8980 就能用，不必再配一个密钥。 只有当 8980 可能被不信任的设备访问（端口转发、公网反代、共享网络）时才建议打开。
仅在「要求 token」打开时使用：Authorization: Bearer <token>。重置后旧 token 立即失效。
用于推送里拼明信片图片的绝对地址，可留空。

引擎时长（FROG_CONFIG）

默认 FROG_FAITHFUL=1，按原版真实时长旅行（小时级）。 改成 0 会使用离线版缩短的时长（适合试玩）。保存后引擎会重启并重新读取存档。
